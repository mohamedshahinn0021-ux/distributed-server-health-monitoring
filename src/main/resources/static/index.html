Finite State Machine (FSM) Specification
4-State Lifecycle Architecture:
ACTIVE
Reachable & Latency ≤ Threshold
SLOW
Reachable & Latency > Threshold
DISCONNECTED
Connection Refused / Timeout
RECOVERING
Reachable; passing 3 stability checks
From State Network Event / Probe Outcome To State System Action
ACTIVE Unreachable (timeout/refused) DISCONNECTED Generate FAILURE alert; reset stability counter to 0
ACTIVE Reachable & Response Time > Threshold SLOW Generate DEGRADED alert
SLOW Reachable & Response Time ≤ Threshold ACTIVE Generate RESTORED alert
DISCONNECTED Reachable again RECOVERING Generate RECOVERY alert; initialize stability counter = 1
RECOVERING Unreachable before completing 3 checks DISCONNECTED Generate FAILURE alert; reset counter to 0
RECOVERING 3 consecutive successful checks achieved ACTIVE Generate STABILIZED alert; server marked fully restored
